i.
RAG'n'Roll — Local RAG News Assistant
A fully local retrieval-augmented generation system: pulls live news from RSS feeds, embeds it into a FAISS vector index, and answers questions grounded only in the retrieved articles — every answer cites its sources. No API keys, no cloud, no data leaving the machine.
Project details
  • End-to-end pipeline: RSS ingestion with trafilatura text extraction and boilerplate cleaning → SQLite (URL-deduplicated) → 1,200-character chunking with 200 overlap → MiniLM embeddings → FAISS cosine-similarity index.
  • Anti-hallucination grounding: the system prompt restricts answers to retrieved sources and enforces inline [1], [2] citations mapped to real URLs.
  • Freshness guard: detects time-sensitive queries ("today", "latest") and forces the model to disclaim recency when retrieved sources lack publication dates — a deliberate defense against confidently wrong "today's news" answers.
  • Streamlit UI with tunable top-k retrieval, one-click index rebuild (ingest → embed), source cards with similarity scores, and a Relevance@k metric.

NYC Taxi Trip Duration Prediction
Neural-network regression predicting NYC taxi trip duration from trip and weather features — designed leakage-free: quantities known only after a trip ends (fare, tips, average speed) are deliberately excluded, so the errors reflect realistic prediction at pickup time.
Project details
  • Data engineering: cleaned 6.4M Jan-2020 Yellow Taxi trips and merged them with daily Meteostat weather; trained on a 314K-row sample with 14 pickup-time features (trip, time-of-day, and 8 weather variables).
  • 3 architectures × 2 optimizers compared in TensorFlow/Keras: linear baseline, MLP, and a deeper DNN with dropout, each trained with Adam and RMSprop under a time-ordered split.
  • Best model: MLP + Adam at 3.31 minutes validation MAE — 22% better than the linear baseline (4.22 min), confirming a real but moderate non-linear relationship.
  • Weather was effectively a date proxy: only 31 distinct daily observations across 314K rows, so the model extrapolates on every weather feature during validation — documented as a limitation rather than reported as a win.
