PROJECT 01
RAG'n'Roll — Local RAG News Assistant
Generative AI · RAG · LLM

A fully local retrieval-augmented generation system: pulls live news from RSS feeds, embeds it into a FAISS vector index, and answers questions grounded only in the retrieved articles — every answer cites its sources. No API keys, no cloud, no data leaving the machine.

project details
  • End-to-end pipeline: RSS ingestion with trafilatura text extraction and boilerplate cleaning → SQLite (URL-deduplicated) → 1,200-character chunking with 200 overlap → MiniLM embeddings → FAISS cosine-similarity index.
  • Anti-hallucination grounding: the system prompt restricts answers to retrieved sources and enforces inline [1], [2] citations mapped to real URLs.
  • Freshness guard: detects time-sensitive queries ("today", "latest") and forces the model to disclaim recency when retrieved sources lack publication dates — a deliberate defense against confidently wrong "today's news" answers.
  • Streamlit UI with tunable top-k retrieval, one-click index rebuild (ingest → embed), source cards with similarity scores, and a Relevance@k metric.

PROJECT 02
Robust Deepfake Detection
Deep Learning · Computer Vision

4-person analytics capstone (co-developer of the ML pipeline). Binary deepfake detection focused on the metric that actually matters for deployment: zero-shot generalization to unseen datasets, not just in-dataset accuracy.

project details
  • 5 architectures trained in PyTorch — ResNet-18, EfficientNet-B4, R3D-18 (3D-CNN), ViT-B/16, and R3D-18 + RAFT optical flow — on 4,200 FaceForensics++ videos with MTCNN 224×224 face crops and class-balanced sampling.
  • Zero-shot cross-dataset test on 6,529 unseen Celeb-DF v2 videos exposed generalization gaps up to 0.24 AUC hiding behind near-perfect (~1.0) in-dataset scores.
  • Soft-vote ensemble won: 0.892 cross-dataset AUC with the smallest generalization gap (0.109), beating every individual model.
  • ViT-B/16 was the best single model (0.884 AUC) — attention-based features transferred to unseen data better than 3D-CNNs, which overfit dataset-specific artifacts.

PROJECT 05
Bank Marketing Classification
Predictive Analytics · ML

Predicted term-deposit subscriptions on the UCI Bank Marketing dataset — 41,188 records with an 88.7/11.3 class imbalance — by benchmarking 6 classifiers, then retuning the top models to prioritize catching actual subscribers.

project details
  • 6 models compared (Logistic Regression, Naive Bayes, KNN, Decision Tree, Random Forest, XGBoost) on 53 one-hot-encoded features with a stratified 70/30 split.
  • XGBoost best by default (F1 0.590, AUC 0.945) — and the analysis shows why raw accuracy is misleading when 89% of customers say "no".

  • Leakage awareness: flagged call duration as the strongest predictor that's only known after a call ends — documented for exclusion in any deployable version.

PROJECT 07
NYC Food Inspection Grade Prediction
Classification · Public Data

Predicts NYC food-establishment inspection grades (A/B/C) from 41K records — built deliberately leakage-free with prior-only history features and establishment-grouped splits, and openly documents the leakage it found and fixed.

project details
  • Leakage found & fixed: an early version scored ~91% — inflated by history features that included the predicted inspection and by random row splits. Rebuilt with prior-only features and GroupShuffleSplit/GroupKFold (verified zero establishment overlap), the honest benchmark is 79.7% accuracy / 0.80 F1.
  • 8 engineered features; an establishment's previous grade is the strongest legitimate predictor (36.8% importance), followed by prior-only failure rate (24.6%).
  • 6 classifiers compared + GridSearchCV tuning, cutting the train–test overfitting gap from 0.24 to under 0.04 while improving test accuracy.
  • Geographic insight: Kings and Bronx counties run ~64% Grade C — strong location-based grade patterns surfaced in EDA.

Healthcare Analytics · Regression
